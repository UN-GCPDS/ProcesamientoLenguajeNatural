# Evidencias

Los tres archivos `T0_*` son la evidencia de arranque aportada por el equipo. La petición HTTP consultó el clima mediante el agente de clase. La captura de credenciales documenta su configuración en n8n.

Para cada prueba del proyecto consigne el criterio de `SPEC.md`, la fecha, el commit, la versión del entorno, la entrada de prueba, el resultado observado y la decisión de cierre. Adjunte la mínima evidencia reproducible, como respuesta JSON, resultado de una consulta o constancia con datos sintéticos. Mantenga las cabeceras de autenticación y credenciales fuera de los archivos.
